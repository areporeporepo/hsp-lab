1The problem

One problem behind Simon, Shor and discrete log

You get a group \(G\) and a black-box function \(f : G \to S\). Someone promises there is a subgroup \(H \le G\) such that \(f\) is constant on each coset of \(H\) and takes different values on different cosets:

\[ f(g_1) = f(g_2) \iff g_1 H = g_2 H . \]

The task is to find \(H\), for example a generating set. For finite abelian \(G\), given efficient group operations and an efficient circuit for \(f\), a quantum computer solves this with \(\mathrm{poly}(\log |G|)\) oracle queries and gates. The recipe is always the same three moves:

\[ \frac{1}{\sqrt{|G|}} \sum_{g \in G} |g\rangle|f(g)\rangle \;\xrightarrow{\ \text{measure } f\ }\; \frac{1}{\sqrt{|H|}} \sum_{h \in H} |g_0 h\rangle \;\xrightarrow{\ \mathcal{F}_G\ }\; \text{uniform over } H^{\perp} = \{\chi : \chi(h) = 1 \ \forall h \in H\}. \]

Each sample is a random character that is trivial on \(H\). \(O(\log |G| + \log(1/\delta))\) samples generate \(H^\perp\) with failure probability at most \(\delta\), and \(H = (H^\perp)^\perp\). The random coset shift \(g_0\) only adds a phase \(\chi(g_0)\), which vanishes when you measure. That is why the Fourier transform is the whole trick.

2Classical side

Factoring reduces to finding a period

Pick \(a\) with \(\gcd(a, N) = 1\). The function \(f(x) = a^x \bmod N\) is periodic with period \(r = \mathrm{ord}_N(a)\). If \(r\) is even and \(a^{r/2} \not\equiv -1 \pmod N\), then \(N \mid (a^{r/2}-1)(a^{r/2}+1)\) but divides neither factor, so

\[ p = \gcd\!\left(a^{r/2} - 1,\ N\right) \quad\text{is a nontrivial factor.} \]

For random \(a\) this works with probability at least \(1/2\) when \(N\) is odd and not a prime power. The hard part is finding \(r\): classically that is as hard as factoring. Change \(N\) and \(a\) and watch the period.

3Fourier

The quantum Fourier transform as gates

On \(n\) qubits with \(Q = 2^n\), the QFT is the unitary DFT matrix:

\[ \mathrm{QFT}\,|x\rangle = \frac{1}{\sqrt{Q}} \sum_{y=0}^{Q-1} e^{2\pi i\, x y / Q}\, |y\rangle = \bigotimes_{\ell=1}^{n} \frac{|0\rangle + e^{2\pi i\, x / 2^{\ell}}|1\rangle}{\sqrt 2}. \]

The product form on the right is why it is cheap: each output qubit only needs a Hadamard plus controlled phases \(R_k = \mathrm{diag}(1, e^{2\pi i/2^k})\). That is \(n(n-1)/2\) controlled phases and \(\lfloor n/2 \rfloor\) swaps, so \(O(n^2)\) gates, against \(O(n 2^n)\) for a classical FFT on the full vector. The simulator below runs the actual gate list on a state vector and compares the result with the DFT matrix entry by entry.

Bars: \(|\langle y|\mathrm{QFT}|x\rangle|^2\). The needle on each bar is the phase \(\arg \langle y|\mathrm{QFT}|x\rangle = 2\pi x y/Q\), drawn as a clock hand. Basis input gives flat magnitudes, so all the information is in the phases. Shor's trick is to feed in a periodic superposition so the phases interfere into peaks.

4Shor 1994

Run Shor's algorithm

Use a register of \(n\) qubits with \(N^2 \le Q = 2^n < 2N^2\). After computing \(f\) and applying the QFT, the probability of measuring \(y\) is exact and has a closed form. With \(M_{x_0} = \lceil (Q - x_0)/r \rceil\) points in each coset,

\[ P(y) = \frac{1}{Q^2} \sum_{x_0=0}^{r-1} \left| \sum_{k=0}^{M_{x_0}-1} e^{2\pi i\, y r k / Q} \right|^2 = \frac{1}{Q^2} \sum_{x_0=0}^{r-1} \frac{\sin^2(\pi\, y r M_{x_0}/Q)}{\sin^2(\pi\, y r / Q)} . \]

At points where \(yr/Q\) is an integer (including \(y = 0\)) the ratio is a removable singularity and each term equals \(M_{x_0}^2\). The distribution peaks at \(y \approx jQ/r\). If \(y\) is a nearest integer to some \(jQ/r\), then \(y/Q\) is within \(1/(2Q) \le 1/(2N^2)\) of \(j/r\), and Legendre's theorem says the reduced fraction \(j/r\) is then a continued-fraction convergent of \(y/Q\). Its denominator is \(r\), or a divisor of it when \(\gcd(j, r) > 1\). Other outcomes can fail, so you sample again and check each candidate with \(a^k \equiv 1\). This simulator skips the trivial convergent \(0/1\), tries multiples \(mk\) with \(m \le \lceil \log_2 N \rceil\), and reduces to the minimal order. Off-peak samples and unlucky \(\gcd(j, r)\) fail, as they should, and you measure again.

What a real machine adds: the modular exponentiation \(|x\rangle|0\rangle \mapsto |x\rangle|a^x \bmod N\rangle\) dominates the cost. For RSA-2048 it is billions of Toffoli gates, and every 2019 to 2026 paper in §8 is mostly about doing that arithmetic with fewer qubits and fewer Toffolis, then protecting it with error correction (§7).

5Simon 1994

Simon's algorithm: the cleanest HSP

Here \(G = \mathbb{Z}_2^n\), \(H = \{0, s\}\) and \(f(x) = f(x \oplus s)\). The Fourier transform over \(\mathbb{Z}_2^n\) is just \(H^{\otimes n}\), and each run returns a uniform \(y\) with

\[ y \cdot s \equiv 0 \pmod 2 . \]

Once you hold \(n-1\) linearly independent \(y\)'s over \(\mathrm{GF}(2)\), Gaussian elimination gives \(s\). That takes a little more than \(n\) runs on average. A classical algorithm needs about \(2^{n/2}\) queries to find a collision. Shor read this paper and generalized it from \(\mathbb{Z}_2^n\) to \(\mathbb{Z}_Q\).

6Regev 2023

Regev: a multidimensional period

Regev (2023) moved factoring from a 1-dimensional HSP over \(\mathbb{Z}\) to a \(d\)-dimensional one over \(\mathbb{Z}^d\) with \(d \approx \sqrt{n}\). Take small primes \(b_1, \dots, b_d\), set \(a_i = b_i^2\), and define

\[ f(z_1, \dots, z_d) = \prod_{i=1}^{d} a_i^{\,z_i} \bmod N, \qquad L = \{ z \in \mathbb{Z}^d : f(z) = 1 \}. \]

The hidden subgroup is the lattice \(L\). The total exponent length is still about \(n\) bits (\(\sqrt n\) exponents of \(\sqrt n\) bits), so that alone saves nothing. The saving comes from the bases being tiny: with simultaneous square-and-multiply, \(f(z) = \prod_j \big(\prod_i a_i^{z_{i,j}}\big)^{2^j}\), all \(d\) bases share only \(O(\sqrt n)\) full \(n\)-bit squarings, and each inner product of small numbers is cheap via a product tree. So one run costs \(\tilde O(n^{3/2})\) gates instead of \(\tilde O(n^2)\). The improvement is per run: you need \(\sqrt{n} + 4\) independent runs, so the total gate count is still about \(\tilde O(n^2)\). The win is a smaller circuit per run, which matters on noisy hardware. Afterward, a classical lattice-reduction step finds a short vector in \(L\) that gives a nontrivial square root of 1 mod N. Pilatte (2024, revised 2026) proved a version of the number-theory conjecture Regev assumed, using zero-density estimates, which gives unconditional correctness for Regev's algorithm and its variants in the form his paper analyzes. Read the paper for exactly how his statement differs from Regev's.

Leading-order scaling only, constants dropped, so compare the shape not the numbers. Regev's original version needed far more qubits; Ragavan and Vaikuntanathan (J. Cryptology 2026) brought it to \(O(n \log n)\), and Van Kirk and Gidney (Oct 2026) to about \(4n\). The best Shor variants (Chevignard, Fouque, Schrottenloher 2025) use about \(n/2\) logical qubits, so for RSA-2048 Shor still wins on qubits.

7Hardware

From logical qubits to physical qubits

A useful heuristic for the surface code at physical error rate \(p\) below threshold \(p_{\mathrm{th}} \approx 10^{-2}\) and code distance \(d\):

\[ p_L(d) \approx 0.1 \left( \frac{p}{p_{\mathrm{th}}} \right)^{(d+1)/2}, \qquad \text{physical per logical} \approx 2 d^2 . \]

If \(p_L\) is the error per logical qubit per round, a union bound says \(p_L \cdot (\#\text{logical qubits}) \cdot (\#\text{rounds}) \le \varepsilon\) keeps memory faults under \(\varepsilon\). That is a sufficient budget in a simplified model; real estimates also budget gate, magic-state and decoding failures. Distance grows only logarithmically with run length, but qubits grow as \(d^2\). That \(d^2\) is the target of the 2024 to 2026 papers: qLDPC codes pack many logical qubits into one block, which is the main lever in both the Pinnacle and the Oratomic neutral-atom estimates.

This is the textbook estimate with no tricks. With the defaults (1,400 logical qubits, \(p = 10^{-3}\), 1 µs cycles, 1 week) it lands in the low millions. Gidney's May 2025 paper gets RSA-2048 under one million physical qubits at the same hardware assumptions by storing idle qubits in denser yoked surface codes, making T states by magic state cultivation, and using approximate residue arithmetic. The logical qubit count here is an input you choose, not a number taken from that paper. Pure surface code only; for a qLDPC comparison, IBM's gross code \([\![144, 12, 12]\!]\) uses 288 physical qubits (data plus checks) for 12 logical, so 24 per logical at distance 12.
