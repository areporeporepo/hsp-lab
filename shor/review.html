L1Qubits

Qubits, amplitudes, measurement

Keep: a state is a unit vector of complex amplitudes, and measuring gives outcome \(x\) with probability \(|\alpha_x|^2\).

\[ |\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \qquad |\alpha|^2 + |\beta|^2 = 1, \qquad \Pr[0] = |\alpha|^2,\ \Pr[1] = |\beta|^2 . \]

After the measurement the state collapses to the observed basis state. A global phase \(e^{i\varphi}|\psi\rangle\) changes no probability, so it is physically invisible. A relative phase (\(|+\rangle\) versus \(|-\rangle\)) is visible after a change of basis:

\[ |\pm\rangle = \tfrac{1}{\sqrt 2}(|0\rangle \pm |1\rangle), \qquad H|0\rangle = |+\rangle,\ H|1\rangle = |-\rangle,\ H|\pm\rangle = |0\rangle, |1\rangle. \]

For L13: the whole HSP algorithm ends in "a global phase \(\chi(g_0)\) disappears when you measure". That is this lecture.

Check: what is \(\Pr[0]\) if you measure \(|-\rangle\)? And if you apply \(H\) first?

\(|-\rangle\) gives \(\Pr[0] = |1/\sqrt2|^2 = 1/2\). After \(H\), \(H|-\rangle = |1\rangle\), so \(\Pr[0] = 0\). The minus sign is a relative phase: invisible in one basis, decisive in another.

L2Tensors

Tensor products and entanglement

Keep: \(n\) qubits live in \(\mathbb{C}^{2^n}\), and measuring part of a system means summing squared amplitudes over the unmeasured part, then renormalizing.

\[ |\psi\rangle = \sum_{x \in \{0,1\}^n} \alpha_x |x\rangle, \qquad (|a\rangle\otimes|b\rangle)_{ij} = a_i b_j . \]

For two qubits, \(\Pr[\text{first} = 0] = |\alpha_{00}|^2 + |\alpha_{01}|^2\), and the second qubit becomes \((\alpha_{00}|0\rangle + \alpha_{01}|1\rangle)/\sqrt{\Pr[0]}\). A state is a product state if it factors as \(|a\rangle\otimes|b\rangle\); otherwise it is entangled. For two qubits, it factors exactly when

\[ \alpha_{00}\,\alpha_{11} = \alpha_{01}\,\alpha_{10}. \]

For L13: "measure the second register \(|f(x)\rangle\)" is a partial measurement. It leaves the first register in a uniform superposition over one coset \(g_0 + H\). This is exactly the rule above.

Check (Tutorial 1): \(|\Psi\rangle = \tfrac{1}{\sqrt2}|00\rangle + \tfrac{i}{2}|10\rangle - \tfrac12|11\rangle\). Find \(\Pr[\text{first} = 0]\), the second qubit after seeing 1, and whether it is entangled.

\(\Pr[0] = |1/\sqrt2|^2 = 1/2\), leaving \(|0\rangle\). Seeing 1 (probability \(1/4 + 1/4 = 1/2\)) leaves \(\tfrac{1}{\sqrt{1/2}}(\tfrac{i}{2}|0\rangle - \tfrac12|1\rangle) = \tfrac{1}{\sqrt2}(i|0\rangle - |1\rangle)\). Entangled: \(\alpha_{00}\alpha_{11} = -\tfrac{1}{2\sqrt2} \ne 0 = \alpha_{01}\alpha_{10}\). Note the post-measurement state of the second qubit depends on the first outcome, which a product state could not do.

L3Strange

Superposition, measurement, non-local correlations

Keep: superposition is not ignorance. \(|+\rangle\) and a fair coin give the same \(\Pr[0]\), but only \(|+\rangle\) can interfere. And acting on your half of an entangled state never changes the statistics on the other half (no-signaling).

\[ |\Phi^+\rangle = \tfrac{1}{\sqrt2}(|00\rangle + |11\rangle): \quad \text{each side alone looks like a fair coin, yet outcomes always agree.} \]

No-signaling (Problem Set 2, Q1): if Alice applies any unitary or measurement to her qubit, the distribution of Bob's measurement outcomes, averaged over Alice's results, is unchanged.

For L13 and L12: no-signaling is the reason "measuring the second register or not" gives the same output distribution on the first register. L12 uses it explicitly.

Check: you measure \(|+\rangle\) in the \(\{|+\rangle,|-\rangle\}\) basis. What do you get? What would a fair coin give?

\(|+\rangle\) gives \(+\) with probability 1. A coin (a 50/50 mixture of \(|0\rangle\) and \(|1\rangle\)) gives \(+\) with probability \(1/2\) in that basis, because \(|\langle +|0\rangle|^2 = |\langle +|1\rangle|^2 = 1/2\). The difference only shows up after a basis change, which is exactly what \(H\) and the QFT do.

L4CHSH

The CHSH game, and the circuit model

Keep: entanglement gives correlations no classical strategy can match: CHSH has classical value \(3/4\) and quantum value \(\cos^2(\pi/8) \approx 0.854\). Computation is a sequence of unitary gates followed by measurement.

\[ \text{win iff } a \oplus b = x \wedge y, \qquad \max_{\text{classical}} \Pr[\text{win}] = \tfrac34, \qquad \max_{\text{quantum}} \Pr[\text{win}] = \cos^2\!\tfrac{\pi}{8}. \]

Gates are unitary (\(U^\dagger U = I\)), so they preserve norm and are reversible. The basic ones:

\[ X = \begin{pmatrix}0&1\\1&0\end{pmatrix},\ Z = \begin{pmatrix}1&0\\0&-1\end{pmatrix},\ H = \tfrac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix},\ \mathrm{CNOT}|a,b\rangle = |a, a\oplus b\rangle . \]
Check: why can no deterministic classical strategy win CHSH on all four inputs?

Write Alice's answers \(a_0, a_1\) and Bob's \(b_0, b_1\). Winning all four needs \(a_0\oplus b_0 = 0,\ a_0\oplus b_1 = 0,\ a_1\oplus b_0 = 0,\ a_1\oplus b_1 = 1\). XOR all four: the left side is \(0\) (each variable appears twice) but the right side is \(1\). So at most 3 of 4 inputs, value \(3/4\); shared randomness is a mixture of deterministic strategies and cannot do better.

L5Universal

Universality of 2-qubit gates

Keep: any unitary on \(n\) qubits is a product of one- and two-qubit gates (CNOT plus single-qubit gates suffice). Universality says what is possible; efficiency, the number of gates, is a separate question.

\[ U = e^{i\alpha}\, R_z(\beta)\, R_y(\gamma)\, R_z(\delta) \quad\text{for any single-qubit } U, \qquad R_z(\theta) = \begin{pmatrix} e^{-i\theta/2} & 0 \\ 0 & e^{i\theta/2}\end{pmatrix}. \]

Problem Set 2 asks you to build any single-qubit gate from \(H\) and \(R_Z(\theta)\). Problem Set 3 asks about combining CNOTs. A generic \(n\)-qubit unitary needs exponentially many gates, so "universal" does not mean "efficient". The interesting algorithms are the ones whose unitaries have short circuits, like the QFT in L10.

For L13: the HSP algorithm is efficient only because \(\mathcal{F}_G\) has a short circuit, a tensor product of small QFTs.

Check: show \(HZH = X\).

\(HZH|0\rangle = HZ|+\rangle = H|-\rangle = |1\rangle\) and \(HZH|1\rangle = HZ|-\rangle = H|+\rangle = |0\rangle\). So \(HZH = X\). Conjugating by \(H\) swaps the \(Z\) and \(X\) bases, the one-qubit case of "the Fourier transform turns shifts into phases".

L6Queries

Reversible computing and the query model

Keep: any classical circuit for \(f\) becomes a reversible quantum circuit (Toffoli gates plus ancillas, uncompute the garbage). In the query model you count calls to the oracle

\[ O_f\,|x\rangle|b\rangle = |x\rangle|b \oplus f(x)\rangle . \]

Phase kickback: put \(|-\rangle\) in the target and the bit flip becomes a sign on the input:

\[ O_f\,|x\rangle|-\rangle = (-1)^{f(x)}\,|x\rangle|-\rangle . \]

For L13: the HSP is a query problem. "Efficient" means few queries to \(f\) and few other gates, and L11's point is that for factoring the oracle itself is efficient.

Check: verify phase kickback for \(f(x) = 1\).

\(O_f|x\rangle\tfrac{|0\rangle - |1\rangle}{\sqrt2} = |x\rangle\tfrac{|1\rangle - |0\rangle}{\sqrt2} = -|x\rangle|-\rangle\). For \(f(x) = 0\) nothing changes. So the phase is \((-1)^{f(x)}\).

L7DJ, BV

Deutsch-Jozsa and Bernstein-Vazirani

Keep the identity that powers everything through L13:

\[ H^{\otimes n}|x\rangle = \frac{1}{\sqrt{2^n}} \sum_{y \in \{0,1\}^n} (-1)^{x\cdot y}\,|y\rangle, \qquad x\cdot y = \textstyle\sum_i x_i y_i \bmod 2 . \]

Both algorithms: \(H^{\otimes n}\), one phase query \(\sum_x (-1)^{f(x)}|x\rangle\), then \(H^{\otimes n}\) again. The amplitude of \(|y\rangle\) is

\[ \alpha_y = \frac{1}{2^n}\sum_x (-1)^{f(x) + x\cdot y}. \]

Deutsch-Jozsa (constant or balanced): \(\alpha_{0^n} = \pm 1\) if constant and \(0\) if balanced. One query, against \(2^{n-1}+1\) for a deterministic classical algorithm. Bernstein-Vazirani (\(f(x) = s\cdot x\)): \(\alpha_y = 1\) exactly at \(y = s\). One query, against \(n\) classically.

For L13: \(H^{\otimes n}\) is the Fourier transform over \(\mathbb{Z}_2^n\), and \((-1)^{x\cdot y}\) are its characters \(\chi_y(x)\).

Check: in BV, why is \(\alpha_s = 1\)?

\(\alpha_s = 2^{-n}\sum_x (-1)^{s\cdot x + x\cdot s} = 2^{-n}\sum_x 1 = 1\). Every term agrees, and since the state is normalized, every other amplitude is 0.

L8Simon

Simon's algorithm, and the discrete Fourier transform

Keep the four-step template: superpose, query, measure \(f\), Fourier transform. Each run gives a random \(y\) with \(y\cdot s = 0\).

Promise: \(f(x) = f(x')\) if and only if \(x' \in \{x, x\oplus s\}\). Run:

\[ \frac{1}{\sqrt{2^n}}\sum_x |x\rangle|f(x)\rangle \;\xrightarrow{\text{measure 2nd}}\; \frac{|x_0\rangle + |x_0\oplus s\rangle}{\sqrt2} \;\xrightarrow{H^{\otimes n}}\; \frac{1}{\sqrt{2^{n+1}}}\sum_y (-1)^{x_0\cdot y}\big(1 + (-1)^{s\cdot y}\big)|y\rangle . \]

The bracket is \(2\) when \(s\cdot y = 0\) and \(0\) otherwise, so \(y\) is uniform over the \(2^{n-1}\) solutions of \(s\cdot y = 0\). The unknown \(x_0\) only contributes a sign. After about \(n\) runs you hold \(n-1\) independent equations and solve for \(s\) by Gaussian elimination over \(\mathrm{GF}(2)\). Classically you need about \(2^{n/2}\) queries to find a collision (the birthday bound).

The DFT on \(\mathbb{Z}_N\), which L9 turns into the QFT:

\[ \hat v_y = \frac{1}{\sqrt N}\sum_{x=0}^{N-1} \omega^{xy} v_x, \qquad \omega = e^{2\pi i/N}. \]

For L13: this is literally the HSP algorithm with \(G = \mathbb{Z}_2^n\), \(H = \{0, s\}\), and \(H^\perp = \{y : y \cdot s = 0\}\). Try the Simon simulator.

Check: why does the offset \(x_0\) not matter?

It appears only as \((-1)^{x_0\cdot y}\), a sign on each amplitude, so \(|{\rm amplitude}|^2\) does not depend on it. In L13 language, the coset shift becomes a character value \(\chi_y(x_0)\) of modulus 1.

L9Shor I

Period finding and the QFT

Keep: the period-finding problem, the definition of \(\mathrm{QFT}_n\), and the state after the oracle and measurement.

Toy problem (course version): \(f\) on \(\{0,\dots,N-1\}\), \(N = 2^n\), with period \(p\) dividing \(N\), and \(f\) takes distinct values within one period. Find \(p\).

\[ \mathrm{QFT}_n|x\rangle = \frac{1}{\sqrt N}\sum_{y=0}^{N-1}\omega^{xy}|y\rangle, \qquad \omega = e^{2\pi i/N}. \]

It is unitary because the columns are orthonormal: \(\sum_y \omega^{(x-x')y} = N\) if \(x = x'\) and \(0\) otherwise (a geometric series of roots of unity). The algorithm is Simon's, with \(H^{\otimes n}\) replaced by \(\mathrm{QFT}_n\). After the oracle and measuring \(f = z\):

\[ \frac{1}{\sqrt{N/p}}\sum_{k=0}^{N/p-1}|x + kp\rangle, \qquad x = \text{smallest input with } f(x) = z. \]
Check: show \(\sum_{y=0}^{N-1}\omega^{jy} = 0\) for \(j \not\equiv 0 \pmod N\).

It is a geometric series with ratio \(\omega^j \ne 1\): \(\frac{1 - \omega^{jN}}{1 - \omega^j} = \frac{1 - 1}{1 - \omega^j} = 0\). This one fact gives unitarity of the QFT, the output of period finding, and in L13 the orthogonality of characters.

L10Shor II

Why the QFT finds the period, and its circuit

Keep: the output is a uniformly random multiple of \(N/p\); a gcd of two samples recovers it; the QFT has an \(O(n^2)\) circuit because its output on a basis state is a product state.

Amplitudes (notes §10.1). Applying \(\mathrm{QFT}_n\):

\[ \alpha_y = \frac{\omega^{xy}}{\sqrt{N/p}\,\sqrt N}\sum_{k=0}^{N/p-1}\omega^{ykp}, \qquad \sum_{k=0}^{N/p-1}\omega^{ykp} = \begin{cases} N/p & \omega^{yp} = 1 \\ \dfrac{1 - \omega^{yN}}{1-\omega^{yp}} = 0 & \text{otherwise.}\end{cases} \]

So \(y = cN/p\), \(c \in \{0,\dots,p-1\}\), each with probability \(1/p\), and \(x\) only enters through the phase \(\omega^{xy}\). Post-processing: \(\gcd(y_1, y_2, \dots) = \tfrac{N}{p}\gcd(c_1, c_2,\dots)\), and two random \(c\)'s are coprime with probability about \(6/\pi^2 \approx 0.61\). Check any candidate with \(f(x) = f(x+p')\).

Comb picture: spikes spaced \(p\) apart transform into spikes spaced \(N/p\) apart, and a shift changes only phases.

Circuit (notes §10.3, \(n = 3\), \(x = 4x_1 + 2x_2 + x_3\)):

\[ \mathrm{QFT}_3|x\rangle = \tfrac{1}{\sqrt 8}\big(|0\rangle + \omega^{4x}|1\rangle\big)\otimes\big(|0\rangle + \omega^{2x}|1\rangle\big)\otimes\big(|0\rangle + \omega^{x}|1\rangle\big) \]
\[ \omega^{4x} = (-1)^{x_3}, \qquad \omega^{2x} = (-1)^{x_2}\, i^{x_3}. \]

The first factor is \(H|x_3\rangle\). The second is \(H|x_2\rangle\) followed by a controlled \(R_2 = \mathrm{diag}(1, i)\) from \(x_3\). In general \(R_k = \mathrm{diag}(1, e^{2\pi i/2^k})\), and \(T(n) = T(n-1) + O(n) = O(n^2)\). Unlike the classical FFT (\(O(N\log N)\), which outputs the whole vector), the QFT costs \(O(\log^2 N)\) gates but only lets you sample from the output.

Try it: the QFT circuit simulator runs this gate list and compares it with the DFT matrix.

Check: in \(\mathrm{QFT}_3\), derive the third factor's phase \(\omega^{x}\) in terms of bits.

\(\omega^x = \omega^{4x_1}\omega^{2x_2}\omega^{x_3} = (-1)^{x_1}\, i^{x_2}\, \omega^{x_3}\) with \(\omega = e^{2\pi i/8}\). So the third factor is \(H|x_1\rangle\), then controlled-\(R_2\) from \(x_2\), then controlled-\(R_3\) from \(x_3\). That is the top row of the circuit.

L11Shor III

Factoring reduces to order finding

Keep: \(f(x) = a^x \bmod N\) has period \(r = \mathrm{ord}_N(a)\), can be computed with \(O(n)\) modular multiplications by repeated squaring, and an even \(r\) with \(a^{r/2}\not\equiv -1\) splits \(N\).

\[ r = \min\{t > 0 : a^t \equiv 1 \pmod N\}, \qquad a^x = \prod_j \big(a^{2^{n-j}}\big)^{x_j} \bmod N . \]

Steps: pick random \(a\), check \(\gcd(a, N)\); find \(r\) (the only quantum step); if \(r\) is odd, restart; set \(b = a^{r/2} \bmod N\). Then \(b^2 \equiv 1\), so \(N \mid (b-1)(b+1)\). \(b \not\equiv 1\) by minimality of \(r\). If \(b \equiv -1\), restart. Otherwise \(p\) and \(q\) cannot both divide the same factor (that would make \(b \equiv \pm 1\)), so

\[ \gcd(b - 1, N) \ \text{and}\ \gcd(b + 1, N) \ \text{are the factors } p, q. \]

From the notes: for a semiprime \(N\), a random \(a\) has even order with probability at least \(1/2\). Modular exponentiation in superposition is by far the most expensive part of a real run. Experiments that pick \(a\) using knowledge of the factors are not genuine runs of Shor's algorithm.

Try it: period explorer and full Shor run. Practice problem 3 is this calculation.

Check: \(N = 21\), \(a = 2\). Find \(r\), \(b\), and the factors.

Powers of 2 mod 21: \(2, 4, 8, 16, 11, 1\), so \(r = 6\). \(b = 2^3 = 8\). \(\gcd(7, 21) = 7\), \(\gcd(9, 21) = 3\). So \(21 = 3 \times 7\).

L12Kitaev

Phase estimation, and Shor as phase estimation

Keep: phase estimation reads an eigenphase into a register using controlled powers \(U^{2^j}\) and \(\mathrm{QFT}^\dagger\). Shor is phase estimation of \(U_a|y\rangle = |ay \bmod N\rangle\) on \(|1\rangle\), an equal superposition of eigenvectors.

\[ |0^n\rangle|\psi\rangle \xrightarrow{H^{\otimes n}} \frac{1}{\sqrt N}\sum_x |x\rangle|\psi\rangle \xrightarrow{\text{c-}U^x} \Big(\frac{1}{\sqrt N}\sum_x e^{i\theta x}|x\rangle\Big)\otimes|\psi\rangle \xrightarrow{\mathrm{QFT}_n^\dagger} \text{measure}. \]

If \(\theta = 2\pi y/N\) exactly, the first register is \(\mathrm{QFT}_n|y\rangle\) and the output is \(y\) with probability 1. Otherwise, with \(\theta = 2\pi\gamma/N\), the output is one of the two integers nearest \(\gamma\) with probability at least \(8/\pi^2 \approx 0.81\). Cost: \(N - 1 = O(1/\varepsilon)\) uses of \(U\), which is optimal. Boost by taking the median of several runs, not the mean.

Eigenvectors of \(U_a\) (notes §12.2.4), with \(\omega_r = e^{2\pi i/r}\):

\[ |\psi_j\rangle = \frac{1}{\sqrt r}\sum_{k=0}^{r-1}\omega_r^{-jk}\,|a^k \bmod N\rangle, \qquad U_a|\psi_j\rangle = \omega_r^{\,j}|\psi_j\rangle, \qquad |1\rangle = \frac{1}{\sqrt r}\sum_{j=0}^{r-1}|\psi_j\rangle . \]

So phase estimation on \(|1\rangle\) returns \(j/r\) for a uniformly random \(j\): with register size \(N' = 2^n\) and \(r \mid N'\), \(y = jN'/r\), the same distribution as period finding. Kitaev's version needs only about \(n + 1\) qubits by recycling one control qubit.

For L13: \(U_a\) is a cyclic shift on the orbit, and its eigenvectors are Fourier vectors. Characters being the eigenvectors of shifts is exactly why the Fourier transform solves every abelian HSP.

Check: verify \(U_a|\psi_j\rangle = \omega_r^j|\psi_j\rangle\).

\(U_a|\psi_j\rangle = \tfrac{1}{\sqrt r}\sum_k \omega_r^{-jk}|a^{k+1}\rangle\). Substitute \(\ell = k+1\): \(\omega_r^{-jk} = \omega_r^{j}\omega_r^{-j\ell}\), and \(a^r \equiv 1\) makes the sum wrap around. You get \(\omega_r^j \tfrac{1}{\sqrt r}\sum_\ell \omega_r^{-j\ell}|a^\ell\rangle = \omega_r^j|\psi_j\rangle\).

The general step, which you have now done three times:

\[ \frac{1}{\sqrt{|H|}}\sum_{h\in H}|g_0 + h\rangle \;\xrightarrow{\ \mathcal F_G\ }\; \sum_{y} \Big(\frac{1}{\sqrt{|G||H|}}\,\chi_y(g_0)\sum_{h\in H}\chi_y(h)\Big)|y\rangle, \qquad \sum_{h\in H}\chi_y(h) = \begin{cases}|H| & y\in H^\perp\\ 0 & \text{otherwise.}\end{cases} \]

The last fact is the L9 geometric-series argument again: a nontrivial character summed over a group gives 0. So each run is a uniformly random \(y\in H^\perp\), each with probability \(|H|/|G|\), and \(O(\log|G|)\) samples determine \(H\). Expect Thursday to also cover discrete log as an HSP over \(\mathbb{Z}_r\times\mathbb{Z}_r\), and why non-abelian groups (graph isomorphism, dihedral) are hard.

Check: in period finding, \(G = \mathbb{Z}_N\), \(H = \langle p\rangle\). Show \(H^\perp = \{cN/p\}\) directly from \(\chi_y(p) = 1\).

\(\chi_y(p) = \omega^{py} = e^{2\pi i py/N} = 1 \iff N \mid py \iff y\) is a multiple of \(N/p\). Since \(H\) is generated by \(p\), being trivial on \(p\) means being trivial on all of \(H\). This is the L10 answer, rederived in one line.
